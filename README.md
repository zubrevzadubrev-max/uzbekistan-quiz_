# Символы Узбекистана

Викторина на пять вопросов для показа на проекторе.

## Запуск в зале

Распакуйте весь архив в одну папку и откройте index.html в современном браузере. Для полного экрана нажмите F11 или откройте меню «Пауза». Фотографии находятся в папке photos. Музыка и звуки синтезируются браузером после нажатия «Начать играть». Игра работает без интернета.

Вариант можно выбрать мышью или клавишами 1–4. После ответа на экране остаётся пояснение. Нажмите «Следующий вопрос» или Enter, когда зал будет готов. Esc открывает и закрывает меню паузы. В меню доступны громкость, музыка, звуки ответов и перезапуск.

## GitHub Pages

1. Загрузите распакованные файлы и папку photos в корень ветки main вашего репозитория. Файл index.html должен лежать прямо в корне.
2. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите main и / (root), затем нажмите Save. После публикации ссылка появится в разделе Pages.
